📌Sobre o Projeto;

Nesse projeto simples iremos sortear um amigo secreto, 
ele é para todos que quiserem efetuar uma brincadeira 
entre amigos ou familia.


Status do Projeto;

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-green)


🚀 Funcionalidades e Demonstração da Aplicação

● Adicionar participantes ao sorteio 

● Remover algum participante caso necessario

● Sorteio aleatorio 

● Interface simples e facil de usar
